
# 📄 PDF Annotator - Fullstack Project

## 📌 Overview
This is a fullstack **PDF Annotation** application where users can upload PDFs, view them, and add annotations/notes.  
It is built with **React (Frontend)**, **Node.js/Express (Backend)**, and **MongoDB (Database)**.

👉 GitHub Repository: [pdf-annotator-fullstack](https://github.com/TanishaRathore5334/pdf-annotator-fullstack)

---

## 🚀 Tech Stack
- **Frontend:** React.js, Axios.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB.
- **Authentication:** JWT.

---
